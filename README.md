# Virtual Try-On

Frontend-only immersive 3D virtual try-on / digital fashion studio.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Stack

- Next.js (App Router) + TypeScript + Tailwind CSS
- Three.js + React Three Fiber + Drei
- Zustand + Framer Motion

See `docs/ASSET_SPEC.md` for production GLB drop-in requirements.
